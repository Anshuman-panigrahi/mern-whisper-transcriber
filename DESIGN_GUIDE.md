headings\n- **Section Title**: `1.8rem` - Card headings\n- **Body Text**: `1rem` - Normal paragraphs\n- **Labels**: `0.95rem` - Form labels\n- **Small Text**: `0.9rem` - Hints, helper text\n- **Tiny Text**: `0.85rem` - Buttons, badges\n\n### **Font Weights**\n- **Bold**: 600-800 - Headings, buttons\n- **Normal**: 400 - Body text\n- **Light**: 300 - Subtle text\n\n### **Line Height**\n- **Headings**: 1.2 - Tight\n- **Body**: 1.6-1.8 - Readable\n- **Form**: 1.4 - Clear\n\n---\n\n## Spacing System\n\n```\nMargin/Padding Increments:\n- 8px (XS) - Tight spacing\n- 15px (S) - Small spacing\n- 20px (M) - Standard spacing\n- 30px (L) - Large spacing\n- 40px (XL) - Extra large\n- 50px (XXL) - Huge spacing\n\nGap (flex):\n- 15px - Form inputs\n- 20px - Card sections\n- 40-50px - Between pages\n```\n\n---\n\n## Buttons\n\n### **Primary Button**\n```\nBackground: #667eea (Purple)\nColor: White\nPadding: 14-16px vertical, 40px horizontal\nBorder: None\nBorder-radius: 50px (pill Up**\n```css\n@keyframes slideUp {\n  from {\n    opacity: 0;\n    transform: translateY(30px);\n  }\n  to {\n    opacity: 1;\n    transform: translateY(0);\n  }\n}\nDuration: 0.5s\n```\n\n### **Spin (Loading)**\n```css\n@keyframes spin {\n  to { transform: rotate(360deg); }\n}\nDuration: 0.8s (infinite)\nBorder: 3px solid rgba(255,255,255,0.3)\nBorder-top: 3px solid white\n```\n\n### **Shake (Error)**\n```css\n@keyframes shake {\n  0%, 100% { transform: translateX(0); }\n  25% { transform: translateX(-5px); }\n  75% { transform: translateX(5px); }\n}\nDuration: 0.5s\n```\n\n---\n\n## Responsive Breakpoints\n\n### **Desktop** (1200px+)\n- Full width cards\n- Side-by-side layouts\n- Hover effects active\n- Large fonts\n\n### **Tablet** (768px - 1199px)\n- Reduced padding\n- Stacked layouts\n- Touch-optimized buttons\n- Medium fonts\n\n### **Mobile** (< 768px)\n- Full width, margins\n- Vertical stack\n- Larger touch targets\n- Smaller fonts\n- Reduced shadows\n\n---\n\n## Error States\n\n### **Error Message**\n```\nBackground: #ff6b6b (Red)\nColor: White\nPadding: 15px 20px\nBorder-radius: 10px\nAnimation: shake 0.5s\nMargin-top: 15px\nIcon: ✗\n```\n\n---\n\n## States\n\n### **Hover**\n- Button up: `translateY(-2px)`\n- Shadow increase: `0 15px 35px`\n- Color change: Slightly darker\n- Cursor: `pointer`\n\n### **Active/Pressed**\n- Button down: `translateY(0)`\n- Shadow decrease\n- Scale: 0.98\n\n### **Focus**\n- Outline: None\n- Border color: Primary purple\n- Box-shadow: Colored halo\n\n### **Disabled**\n- Opacity: 0.5\n- Cursor: `not-allowed`\n- Hover: No effect\n\n---\n\n## Loading States\n\n```\n🔄 ← Spinning icon\n\"Processing...\"\n\"Logging in...\"\n\"Creating Account...\"\n```\n\n---\n\n## Success States\n\n```\n✨ Transcript Result\n✅ Action completed\n💾 Data saved\n✓ Validation passed\n```\n\n---\n\n## Professional Touch\n\n1. **Shadows**: Multiple layers (0 10px 30px, 0 20px 60px)\n2. **Gradients**: Smooth 135deg angle\n3. **Rounded Corners**: 10-25px consistency\n4. **Spacing**: Consistent 20px grid\n5. **Typography**: Single font family\n6. **Color Contrast**: WCAG AA compliant\n7. **Animations**: Smooth, not jarring\n8. **Icons**: Unicode emoji (simple, clear)\n\n---\n\n## Implementation\n\nAll styles are in `client/src/App.css` (500+ lines)\n\nNo external CSS framework needed - pure CSS with:\n- Flexbox for layouts\n- CSS Grid (optional)\n- CSS Variables (optional)\n- Media queries for responsive\n- Keyframe animations\n- Gradient backgrounds\n\n**Total Styling: Professional, modern, production-ready!**
